# Screenshot and Demo Guide

Release media must demonstrate behavior without exposing a real Vault.

## Screenshot set

Capture at least:

1. Home in the default macOS light theme at a desktop-width layout;
2. Study or Research showing explicit Native/optional source status; and
3. Agent showing target selection, review-before-write labels, and the statement
   that provider/model/authentication stay in Claudian/the Agent.

Use synthetic note names and metadata. Crop the Vault sidebar, title bar username,
local paths, notices, Agent conversations, and provider configuration. Check both
light and dark themes, 200% zoom, keyboard focus, reduced motion, and narrow
one-column reflow before choosing release images. Store approved images below
`docs/assets/` with descriptive alternative text in the README.

## Two-minute demo

1. Open the Dashboard from the command palette.
2. Move between Home, Study, Research, and Agent with arrow keys in the page tab
   list.
3. Turn on layout editing, move one Widget with the keyboard, press Escape, and
   reopen the Dashboard to show persistence.
4. Show a plain-Vault fallback and explain that optional plugins are not
   required.
5. On Agent, switch Codex/OpenCode, choose a read-only workflow, and stop after
   Claudian prefill. Explain that the user verifies the target and sends.

Do not send a real Agent request, create a note, or reveal private content merely
to record a demo.
